## 实现与兼容性

- API 拆为应用装配、上传中间件、配置、任务、资源；队列管理与单任务执行、状态恢复分离。
- 材料解析、完整回答、视频规划/检查/时间线/渲染、多模型调用和凭据各有明确所属模块。ContentStore 仅接收根目录和上传限额，业务服务显式接收配置。
- 前端以原生 ES modules 装配工作区、结果、设置、HTTP 和 DOM 操作；无新增框架或构建步骤，保留已有页面设计。
- 测试按能力归档，公共样例在 `tests/support/`；付费评测统一为 `python -m evals.<模块>`，题目集在 `evals/cases/`，启动和打包工具留在 `scripts/`。
- 文档归为 current/design/research/archive，README 指向唯一导航；历史成功与失败证据保留。
- 新旧完整 OpenAPI JSON 相等，共 21 条路径；CLI 命令、存储集合、公开 JSON、ID、提示词、检查回执和版本绑定约定保持兼容。

复核修正了两个既有边界：无 `text` 模型时统一界面与运行的默认模型选择；解析进程启动后立即遇到预算失败也执行 kill/wait。拆分中另修正视频配置传递，确保上下文估算、provider 与共享预算使用同一视频快照和实际输出预留。

## 浏览器验收

使用独立的 127.0.0.1:8767 服务和隔离私有目录。页面操作通过真实浏览器完成，模型传输为受控 MockTransport：

- 设置模型地址、名称、无鉴权模式，执行文本/结构化探测并保存。
- 提交问题得到完整正文、数学公式和来源；刷新/重新打开后恢复已完成任务。
- 载入拆分前保存的真实 Answer/Video，331 秒旧视频的媒体状态 readyState=4，实际播放推进到 8.61 秒，无媒体错误。
- 人工修订生成新 Answer ID，原版本保持可读，原视频从新版本视图脱离。
- 390 像素窄屏无页面横向溢出；浏览器未记录控制台 error/warn。验收后恢复视口并关闭自建标签和服务。
