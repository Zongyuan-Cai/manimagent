# 项目 Review 与代码整理验收

日期：2026-11-06。基于 `E:\manimagent` 当前工作树完成；保留此前未提交的上传、配置与记忆功能，没有重置工作树。本轮未提交、推送或操作远端 issue。代码组织见[当前架构](../../docs/current/代码架构与迁移.md)。

## 审查结论与修复

审查覆盖 API、CLI、任务调度、材料解析、文字回答、记忆、模型连接、视频/语音、网页、测试、评测入口和发行脚本。以下问题已修复并有确定性回归；不把“扫描没有报警”解释成项目不存在其他缺陷。

| 问题 | 触发与影响 | 修复 |
|---|---|---|
| 取消后的记忆用量可能丢失 | 模型仍在调用时取消，随后大量任务触发历史裁剪，晚到回包找不到任务记录 | 保护待结算摘要，同时计入未完成容量；总历史仍不超过 200；只结算一次，重启保留未知用量并释放保护 |
| 停止服务可能中途放弃排空 | 某个排队任务读写或对账失败，后续任务与队列容量未释放 | 每项独立处理失败，`finally` 释放容量和队列计数，剩余任务继续处理；重启恢复未成功落盘状态 |
| 保存正文存在竞态 | 重复保存、保存期间再次生成，或旧请求迟到时错误解锁新任务 | 独立保存锁及响应归属检查；保存失败保留原任务轮询，继续支持动画中保存新版本 |
| 文本段首缩进丢失 | 代码或日志段落以空格、Tab 开头 | 保留原缩进与准确行号 |
| Notebook 完整性误报 | 输出只有不支持的富 MIME 类型，却仍标记已完整读取 | 明确记录未读取输出并转为待核对；保留可读文本与 LaTeX，不新增格式解析器 |
| 代码围栏错误切分 | 外层四个反引号包含三个反引号，或关闭行带有不合法后缀 | 按围栏字符、长度和合法结束行匹配，保留正文字符范围；规划版本升至 13，旧分块不被错误复用 |
| 解码失败误报超时 | 上游响应宣称 gzip，但正文无法解码 | 返回 `invalid_provider_response`，保持最多两次尝试与既有用量记录，不暴露上游正文 |
| 就绪错误被界面覆盖 | 服务状态请求失败后切换输出选项 | 保留实际失败状态，避免错误重绘为“正在读取” |

另外澄清 writer 引用指令：复制实际 `material_id`、`block_id` 的值，不把字段标签放入引用。严格引用校验保持不变，并覆盖错误标签的拒绝行为。此项未重新调用真实模型，不能声称已消除所有模型引用失败。

## 代码组织与清理

| 边界 | 当前职责 |
|---|---|
| `storage.py` / `content_store.py` / `materials/detection.py` | 原子 JSON I/O、资源发布、上传类型识别分离；配置模块不再间接加载材料模块 |
| `materials/parsers.py` | 仅负责格式分发；文本、PDF、DOCX 分别在 `text.py`、`pdf.py`、`docx.py`；共享块/来源/字符限制在 `blocks.py`，Office 容器检查在 `archive.py` |
| `memory/database.py` | 统一 SQLite schema、事务、修订、取消围栏与提交回执；`MemoryStore` 和 `LearningStore` 不再互相调用私有方法，数据库层不代替条目策略清理 |
| `video/units.py` / `planning.py` | 原 Markdown 无损单元划分与模型规划分离 |
| `llm/credentials.py` | 核心模型与语音复用密钥草稿校验，保留原 API 字段和私有存储规则 |
| `web/memory-learning.js` / `memory.js` | 沉淀任务视图与 HTTP、轮询、编辑锁分离 |
| `tests/support/memory.py` | 共享时钟、证据、模拟 provider 与等待逻辑，不再从其他测试用例导入帮助函数 |

确认无调用后移除：`LearningStore.view`、未使用的 `LearningState` 别名、`finish(entries=...)` 参数、历史裁剪的无效 `reserve` 参数、`prepare_memory` 的无效 instruction 参数、上传的无效浏览器 MIME 参数，以及 `httpx2` 开发依赖。合并重复 DOCX MIME 常量、Office 容器检查和密钥校验，删除移动后的重复实现与无用导入。

静态检查覆盖 `src/manimagent`、`scripts`、`evals`，并人工核对引用；Vulture 高置信候选仅剩框架校验器 `cls`。FastAPI 路由、Pydantic 字段/校验器、解析和渲染 worker、Manim `construct` 等动态入口保留。前端引用检查未发现可安全删除的独立模块或样式，`.math` 由后端 Markdown 生成。没有扩大附件支持范围、放宽引用校验或删除验证入口。

uv build --out-dir dist/project-review-20261106
