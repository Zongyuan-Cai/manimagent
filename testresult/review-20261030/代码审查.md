| 级别 | 问题与实际后果 | 修复与验证 |

| P1 | PDF 绘图检查漏掉 `F`、`b`、`b*`。包含必要图形的页面仍流入文本生成，图形含义已经消失；基线三个样本都花费两次模型调用后才要求补充条件。 | [materials.py](../../src/manimagent/materials.py) 补齐路径绘制操作符。九种路径绘制变体均通过回归，四种真实服务场景在解析阶段拦截，零模型调用。 |
| P1 | 缺少数值数据时，checker 把“诚实解释不能计算并给出公式”当作完成原任务。均值样本实际产生正式 Answer，状态为 `completed`。 | [answers.py](../../src/manimagent/answers.py) 加强通用提示词：按原始请求是否完成判定，具体数值请求缺必要数据时必须 `needs_input`，任一必要子问题缺条件也如此。五种缺条件问题和 CLI 场景实测正确；方法讲解、有数据均值和符号公式仍正常完成。此修复降低误判，不构成确定性保证。 |

## 多 LLM 源：实际支持到哪里

当前 `ChatProvider` 实现的是 **Chat Completions 协议的多配置接入**。每条配置可设置模型、根地址或完整操作地址、鉴权、JSON 模式、token 参数和输出预算；writer／checker 分别绑定配置，任务接受时固定快照。配置保存、凭据隔离、热应用及重启恢复已有实现，本轮也做了真实调用验证。

本次只得到 DeepSeek 凭据。真实测试验证了官方根地址、`/v1`、完整 URL、`max_tokens`／`max_completion_tokens`、JSON 对象模式／提示词 JSON，以及自定义 Authorization 头。两个角色使用不同配置，但厂商数始终是 1。已有受控传输测试验证独立配置与凭据、旧任务快照、401／402／404／408／429／5xx 分类、有界重试、异常响应及截断；这些不能代替其他厂商的真实验收。

Responses、Anthropic Messages、Gemini 原生协议、原生文件输入及跨厂商故障转移尚未实现。后续“多 LLM 源验收”应逐条登记目标服务、协议、模型、普通文本／结构化输出、错误和用量证据；新增一种源不能只测试连接成功。当前官方 API 的协议依据见 [DeepSeek Chat Completion 文档](https://api-docs.deepseek.com/api/create-chat-completion/)。

## 多输入格式与完整输出

已真实验证直接文本、UTF-8 TXT（含 BOM／CRLF）、Markdown、文本型 PDF、PDF 选页、DOCX 普通段落／表格、同名多文件及跨文件条件。扫描件、题图、公式对象、上下标等不完整提取不会冒充成功。独立图片、CSV、PPTX、OCR 和音视频仍不支持。

正文以 writer 原始 Markdown 保存，来源 ID 由程序检查；检查未通过、截断、调用预算不足时不发布 Answer。读取、下载和步骤索引无损一致。修订产生新版本并标记未经重新模型检查；直接复用既有答案无需模型。通用 system prompt 的实际请求摘要中，writer／checker 各只有一个固定哈希，未注入学习历史或长期记忆。

## 保留的限制与质量缺口

1. **模型内容检查仍有漏判。** 人工抽查发现 `derivative_text` 把“微分”直接描述为瞬时变化率，术语不严谨；实际计算 `f'(2)=10` 正确，checker 仍通过。该例保留在 [manual-review.json](manual-review.json)。110 项流程断言通过不能解释为 100% 内容正确。应扩充人工标注的概念与推理评测集，并利用已实现的角色绑定验证不同检查模型的效果。
2. **长材料预算偏保守。** 上下文按 UTF-8 字节估算并包含块元数据。16060 字符、100 条记录的样本，writer 输入估算达 59187，加输出预留 6000 后超出测试配置 48000；零调用拒绝符合设计。把该样本的模型窗口设为 128000、回答预算设为 96000 后才放行。下一步可压缩不必要元数据并引入经过验证的 tokenizer；不能通过静默截断解决。
3. **耗时数据不等于生产承诺。** 本轮是少量并行的独立测试应用，单应用仍为一个 worker；短题与两个长场景均在十余秒内完成。未做持续负载、长队列、网络抖动及其他厂商的真实容量测试。任务执行预算从出队开始，排队等待另算；生产 SLA 需要单独覆盖等待时间。
4. **格式识别有明确边界。** 保守拦截可以包含装饰性绘图或虽无害但带上下标的文档；文本型 PDF 的复杂公式仍可能在字符映射正常时提取错误。当前不能宣称任意数学 PDF／DOCX 无损解析。

验证结果、耗时、token 用量、复现方法及最终场景矩阵见[真实测试报告](真实测试报告.md)。
