# 用户分层记忆：实现与验收

日期：2026-11-06。工作树：`C:/Users/20557/.codex/worktrees/docs-av-alignment/manimagent`，分支 `codex/text-pipeline-review-20261030`。沿用已接入 MiMo 的开发版本，未将改动复制到 `E:/manimagent` 的旧文字版 main。

## 本轮实现

- 统一用户记忆，以字段保存内容，以 `short_term / deep` 表示层级；不加入生成器经验或画像摘要合并。
- SQLite 事务、原句来源核验、独立会话支持、三会话晋升、确认／纠正／删除，以及过期和容量清理。
- 同来源幂等，删除后的同来源重放不复活；临时要求只在本会话使用，深层不因未访问而自动删除。
- 网页管理面板、任务记忆开关、明确新会话入口及 HTTP API；默认关闭，CLI 未新增记忆命令。
- 仅从用户 `instruction`／记忆输入提取，不从上传材料或模型答案推断用户属性。提取复用回答模型，有输出、时间和调用限制；不足时优先保留正文预算。
- 文字生成前固定有界快照，Answer、人工修订及后续视频使用同一份快照。
- 更新使用、设计、架构、开发计划和研究文档；记忆与音画对齐保持两条独立研究方向。

本轮发现并修复的缺陷：

1. 新的记忆类型是渲染器契约的传递依赖，原缓存指纹遗漏这两个文件；现已纳入，并扩展修改记忆模型即使缓存失效的测试。
2. 更正内容包含控制字符时原先返回 500；现由请求校验返回 422，并保持原条目不变。
3. 可选提取原先只保留调用次数；现还预留正文／检查的 token 和时间，验证低预算时跳过提取但成功完成回答。
4. 真实计划检查返回 `decision=revise` 却给空修复场景列表，导致局部修复不能继续。现由模型输出契约拒绝该结构并进入现有的有限格式重试；旁白提示补充复合分子的明确读法，检查不再假装已经听到尚未合成的音频。修改后的动画、记忆相关测试 **78 passed**，28.80 秒。

## 验收范围

首版以规范化精确匹配、固定会话阈值和时间／容量规则作为工程基线，未实现语义合并或自动降级。深层占满时要求用户删除不需要的条目；来源去重索引满 10000 条后停止新增，不静默丢弃防重放记录。

来源片段存在不等于模型语义提取必然正确；有记忆上下文不等于所有视觉偏好必然执行。个性化仍受可信模板能力限制。没有进行大规模提取准确率评测、学习型策略对比、真人学习实验或完整视频人工听看，不据此声称论文贡献已经验证。

删除作用于活动记忆库及后续使用；历史 Answer、视频和诊断中的固定快照保留，不声称全量个人数据擦除。测试使用虚构偏好与隔离数据，不把测试记忆写入日常用户库。
