# DeepSeek 官方 Flash 全链路测试报告

日期：2026年10月29日。当前版本为独立的 0.2.0 文字开发版，使用用户指定的 DeepSeek 官方接口和 `deepseek-flash`，writer 与 checker 均真实调用，没有使用生产模拟成功模式。首个最小请求、两类连接测试、完整回答和检查均成功；模型 ID 同时按[官方调用文档](https://api-docs.deepseek.com/)核对。

本报告及 `current-pytest.txt` 保留文字链路验收时的 63 项回归记录。后续 PR 流水线增加了 12 项打包边界测试；最新 GitHub Windows／Linux 回归均为 75 项，见 [CI 实测记录](https://github.com/Zongyuan-Cai/manimagent/actions/runs/40893151478)。这项补充不代表重新运行了真实模型测试。

API Key 仅在应用私有凭据存储中由 Windows DPAPI 保护，本报告、材料、源码和诊断不保存密钥值。静态扫描记录见 secret-scan.json。

## 结论

- 修复后真实主链路 **21/21** 通过；初测 **16/21** 的证据保留在 baseline，缺陷与测试断言差异逐项见[代码审查](代码审查.md)。
- 独立阶段、人工修订、HTML 转义、零调用复用、输入预算与连接测试的补测 **8/8** 通过，见 supplemental/summary.json。
- 当前自动化回归 **63 passed**；历史项目独立回归 **83 passed，1 skipped**。跳过项为需要显式启用的历史 Docker 集成测试，没有把它算成通过。
- 浏览器真实上传了 PDF 第 2 页、DOCX 与 Markdown 的组合，完整回答中 **37 处公式全部排版、1 个对比表格**正常显示；来源可展开到选定页。实际下载与已保存 Markdown 逐字一致。
- 扫描页与不支持图片在浏览器中明确提示问题，不发布完整答案。失败状态不再残留“正在准备／正在上传”；刷新仍能恢复已保存任务与回答。
- 当前与历史 MVP 的源码、环境、配置、依赖、API、命令、数据、测试和发布包已分离，见 architecture.json。当前 wheel／sdist 不含历史项目、测试材料、结果或私有配置。

## 本轮修复与边界

修复了 PDF 绘图漏检、文件名上下文缺失、正文相邻公式未排版、中文粗体、标题误取代码注释、结构化结束判定、关闭阶段状态、失败进度残留和静态资源缓存。清理了当前版本中的旧动画模块、契约、配置、命令、依赖、重复诊断与无用样式；细节见[代码审查](代码审查.md)。

当前不具备 OCR、扫描／题图理解、复杂 Word 公式可靠提取、PPTX／音视频解析、多用户部署或动画生成。测试材料是固定人工样例，不代表任意真实教材的成功率。DOCX 原件的 LibreOffice PDF 预览因 bundled LibreOffice 不可用而未列为通过项；已检查 OOXML／表格／阅读顺序和应用生成结果，PDF 样本另有渲染预览。

旧虚拟环境备份与历史 smoke 产物的清理命令被自动审批拒绝，已保留并排除当前运行、Git 和打包；没有以其他删除方式绕过拒绝。
