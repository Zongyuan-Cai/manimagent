# 代码审查与版本隔离

日期：2026年10月29日。范围为当前生产 Python 模块、网页脚本和样式、配置、依赖、测试、打包与历史 MVP 边界。真实测试结果见[测试报告](测试报告.md)。

## 已发现并修复的问题

| 优先级 | 问题与影响 | 修复与验证 |
|---|---|---|
| P1 | PDF ContentStream 字典可能为空，`if contents` 把实际存在的绘图流当成不存在，漏掉题图且消耗回答调用 | 改为 `is not None`；矢量题图实测 needs_review、模型调用 0，新增精确复现测试 |
| P1 | 展示公式紧接正文且没有空行时，Markdown 段落吞掉公式边界，网页显示原始 LaTeX | 添加段落边界规则；真实答案的 37 处公式全部转成 MathJax，表格公式正常；下载正文不改写 |
| P2 | 上下文只有 file_id，没有 filename，同名文件引用要求无法完成 | ContextBundle 附加可核对的来源元数据；多文件真实复测通过，两个同名文件仍以独立 ID 关联 |
| P2 | 当前服务仍导入并启动历史动画 Worker，挂载旧接口，依赖 LangGraph 和动画契约 | 历史 0.1.0 冻结为独立项目；当前只注册 v2，旧接口返回 404，不导入动画或 LangGraph |
| P2 | 服务关闭时排队 Job 已中断，但 Generation 阶段仍显示 pending | 统一中断与已发布回答核对逻辑，同步 Job／Generation；新增停止队列回归 |
| P2 | 最终诊断写入失败可能把已持久化并登记的完整文字误标为失败 | Worker 异常处理先核对已发布回答引用，再判断失败；与重启核对共用逻辑 |
| P2 | 检查报告可能接受没有确认 stop 的结构化响应，这是旧兼容行为 | 当前 writer／checker 均要求可靠结束；拒绝、截断、工具回合及未知结束不发布成功结果 |
| P2 | 上传失败仍显示“正在上传”，待核对终态仍显示“正在准备” | 清理失败进度提示，终态无完整 Answer 时明确说明未发布；真实浏览器重测通过 |
| P2 | 浏览器可能保留旧版脚本；条件缓存使修复未在已打开页面生效 | 首方资源禁缓存并为入口加版本，条件请求回归通过；MathJax vendor 保持独立 |
| P2 | sdist 因环境示例的忽略规则误带一份 legacy 文件 | 对当前 sdist 使用明确白名单；wheel／sdist 均验证无 legacy、材料、结果或凭据 |
| P3 | 标题提取会把代码围栏中的注释识别为回答标题 | 改为读取 Markdown 标题 token；正文与步骤不变 |
| P3 | 中文粗体标点紧接正文会显示字面量星号 | 增加受限的中文标点规则，不影响代码围栏，真实页面已验证 |

初测中的另外 3 个失败来自测试构造／断言：题目投影方向不够明确，或正确的 `\frac32` 不被只接受小数／带花括号形式的断言识别。已明确题设并支持等价分数表达，没有通过放宽失败状态来掩盖实现问题。

## 清理的无用代码与混用内容

- 当前源码中的规划 Agent、ArtifactStore、动画 JobManager、GenerationEngine、DockerRenderer、容器驱动与旧动画结构，全部只留在 legacy_mvp。
- 当前 API 不再构建动画引擎、执行旧 readiness 或注册 `/api/jobs`；CLI 删除 generate、smoke 和旧 --text-only 分支。
- 删除只有动画消费者使用的 Provider Protocol 与图片请求编码分支；当前服务没有伪装可用的视觉输入路径。
- 当前 Settings 删除所有动画参数、视觉角色默认值和视觉环境模板；依赖与锁文件移除 LangGraph 及其传递依赖，当前虚拟环境已重新建立。
- 删除 `_Record` 伪 schema 包装、重复 Markdown 诊断保存、重复请求正文日志和重复轮询测试帮助函数。
- 清除旧视频播放器、动画占位、进度条、徽标及未使用的 CSS；第三方 MathJax 为当前公式排版所需，保留固定版本和许可证。
- 删除并重建原 tests 目录：当前测试按 unit／integration 分类，历史回归只在 legacy_mvp/tests 中运行。
- 当前 Dockerfile／Docker 忽略文件已移出活动项目；历史项目保留自己的完整版本。原 0.1.0 构建产物归档到 legacy_mvp/dist/original-builds。

Ruff 检查与格式检查通过；Vulture 的 100% 置信度扫描在排除框架约定参数 cls／env／options 后未报告未处理项。这不是对所有动态调用的形式化证明，路由和 Pydantic 回调另结合调用位置与回归人工核对。

## 隔离验收

| 项目 | 当前 0.2.0 | 历史 0.1.0 |
|---|---|---|
| 源码与安装 | 根目录 src/manimagent 与 .venv | legacy_mvp 自有 src 与 .venv，不混装 |
| 配置与数据 | 根目录模板，默认 runs/current/private | 归档目录内自己的配置与 runs |
| 入口 | v2，serve／answer／doctor，端口 8000 | 原 API 与动画 CLI，端口 8001 |
| 依赖和锁 | 当前 uv.lock，不含 LangGraph | 自有 uv.lock 与动画依赖 |
| 测试 | 重建的 tests/unit、tests/integration | 自有 tests，83 passed、1 Docker skipped |
| 发布 | dist/current，仅当前源码与必要静态资源 | 归档项目独立构建 |

当前架构测试验证旧接口不存在、旧命令不在帮助中、动画配置字段被拒绝、导入当前 app 不加载历史模块。发布包内容验证记录见 architecture.json。CI 分为 current 与 legacy 两个独立 job。

## 保留的边界

OCR、扫描／题图理解、复杂公式可靠识别、PPTX／音视频、多协议控制面、动画接入和多用户部署没有在本轮实现。解析是有限时间子进程，并非操作系统级内存安全沙箱。真实模型成功样例只证明这组固定材料，不证明任意教材准确率。

旧虚拟环境备份和历史 smoke 产物的清理命令被自动审批拒绝，因此保留原位；它们已被当前运行路径、Git 和发布范围排除，没有改用其他方式绕过拒绝。当前环境与历史项目分别通过自己的回归，保留的备份不参与运行。
