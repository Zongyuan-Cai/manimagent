## 清理的错误掩盖行为

| 位置 | 过去的处理 | 现在的行为 |
|---|---|---|
| `config.py` | 显式配置文件不存在、空／假值 YAML、未设置变量被当作默认或空值 | 显式报错；仅首次启动未提供默认文件时允许初始默认设置 |
| `llm/settings.py` | 网页已保存配置合并后绕过整体校验 | 加载时重新验证角色引用与字段范围，损坏配置直接失败 |
| `llm/credentials.py`、设置页面 | 本地密钥丢失当作未配置；未知编码当作明文；解码错误导致设置页不可用 | 明确的凭据错误；页面显示原因并允许替换；无鉴权调用不读取旧密钥 |
| `llm/client.py` | 超出上下文预算时丢掉失败候选后重新生成 | 保留候选的修复超限即报错；禁止重试时保留原始输出校验错误 |
| `llm/client.py`、`video/tts.py` | 非法／假值用量被忽略 | 对非法类型和 token 数报错；缺省或 null 仍表示未报告 |
| `materials/parsers.py`、`process.py` | 任意程序异常或子进程失败均标成用户文件损坏 | 已知损坏输入仍要求补充原件；程序、依赖及环境错误保留失败与 stderr；非零退出不能发布结果 |
| `materials/structured.py` | Notebook 缺少源码／输出字段时补空，缺少输出类型时猜测 | 根据单元与输出类型读取必填字段，异常结构明确失败 |
| `memory/service.py`、`projection.py` | `{}` 被当作成功的空提取；快照缺失条目当作无记忆 | 提取必须显式返回 `candidates`；缺失快照结构报错 |
| `memory/audit.py`、`files.py` | 损坏请求被描述为没有记忆；同步捕获所有异常 | 无效审计记录报错；同步只处理预期文件／领域错误，程序及数据库异常继续暴露 |
| `video/notation.py` | 猜测补分式反斜杠、合并重复转义 | 非法公式交回校验失败，保留合法语法与明确别名转换 |
| `video/renderer/process.py` | 无权读取进程内存时跳过资源检查 | 停止渲染并报告监控不可用 |
| `jobs/execution.py`、`scripts/launch_local.py` | 缺少受理时间时重新计算排队预算；任意端口错误都继续换端口 | 必需记录缺失直接失败；仅端口占用允许尝试下一端口 |

保留有明确产品语义的行为：有限且可追踪的网络重试／模型修复、任务重启恢复、正文已发布后的部分完成、数据库提交后的文件镜像错误报告，以及历史未知用量／快照。它们不会把失败伪装为完整成功。
