选定页只给出
[ a=(3,2),\qquad b=(2,0), ] 并要求求投影系数和投影向量 来源 1。该页未明示“谁投影到谁”，按常见顺序，先求 \(a\) 在 \(b\) 上的投影。

设投影系数为 \(k\)，投影向量为 \(p\)，则
[ k=\frac{a\cdot b}{b\cdot b},\qquad p=kb. ]

计算： [ a\cdot b=3\cdot 2+2\cdot 0=6, ] [ b\cdot b=2^2+0^2=4. ] 因此 [ k=\frac{6}{4}=\frac32. ] 投影向量为 [ p=\frac32(2,0)=(3,0). ]

所以，\(a\) 在 \(b\) 上的投影系数为
[ \boxed{\frac32}, ] 投影向量为
[ \boxed{(3,0)}. ]

验证：\(a-p=(3,2)-(3,0)=(0,2)\)，且 [ (a-p)\cdot b=(0,2)\cdot(2,0)=0, ] 故 \((3,0)\) 确为 \(a\) 在 \(b\) 方向上的正交投影向量。

若题意反指“\(b\) 在 \(a\) 上的投影”，则投影系数为 [ \frac{a\cdot b}{a\cdot a}=\frac{6}{13}, ] 投影向量为 [ \frac{6}{13}(3,2)=\left(\frac{18}{13},\frac{12}{13}\right). ] 但按通常“前一个向量投影到后一个向量上”的约定，答案应为
[ \boxed{k=\frac32,\quad p=(3,0)}. ]
