## 独立补充控制

- [第一次抽取控制](extraction-control/报告.md)：失败。即使要求保留原句，模型仍增删“我偏好”，两个条目各支持两个会话，没有晋升。
- [第二次抽取控制](extraction-control-v2/报告.md)：改为 value 与单事实 evidence 逐字一致并给示例后，七步全部通过。同一条目支持数 `1→1→2→3`，第三个独立会话自然升为 deep，confirmed_at 为空；同源重放零模型调用且状态不变；两个负例不写入。这是固定原句的小样本控制，不代表所有措辞均可靠。
- [清退控制](retirement-control/报告.md)：一次真实抽取新增不同字段的临时偏好，再只推进测试实例时钟十六天。清退前短期条目仍物理存在，但已被 snapshot 排除；cleanup 删除 1 条过期记忆，保留原自然 deep，内容与 ID 不变且仍可检索。没有改系统时间，也未覆盖第二次控制的原始七步证据。

补充控制共 **13 次真实提取调用**，以及 2 次零调用重放。它们独立验证规则，不能覆盖主轨迹失败或补记为第二十轮。
