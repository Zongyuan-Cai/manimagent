投影计算

给定
[ a=(3,2),\qquad b=(2,0) ] 来源 1

按材料中的投影公式： [ c=\frac{a\cdot b}{b\cdot b},\qquad p=cb ] 来源 2

先计算点积： [ a\cdot b=(3,2)\cdot(2,0)=3\cdot 2+2\cdot 0=6 ]

\[ b\cdot b=(2,0)\cdot(2,0)=2^2+0^2=4 \]

因此投影系数为： [ c=\frac{a\cdot b}{b\cdot b}=\frac{6}{4}=\frac{3}{2} ]

投影向量为： [ p=cb=\frac{3}{2}(2,0)=(3,0) ]

所以，\(a\) 在 \(b\) 方向上的投影向量是： [ \boxed{p=(3,0)} ] 对应的投影系数是： [ \boxed{c=\frac{3}{2}} ]

可验证投影的垂直关系： [ a-p=(3,2)-(3,0)=(0,2) ] [ (a-p)\cdot b=(0,2)\cdot(2,0)=0 ] 说明 \(a-p\) 与 \(b\) 垂直，符合正交投影。

系数与向量对比

材料中给出的向量坐标为：

向量 坐标
\(a\) \((3,2)\)
\(b\) \((2,0)\)

来源 3

对比计算结果如下：

对象 符号 类型 计算式 结果 含义
投影系数 \(c\) 标量 \(\dfrac{a\cdot b}{b\cdot b}\) \(\dfrac{3}{2}\) 表示沿 \(b\) 方向缩放的比例
投影向量 \(p\) 二维向量 \(cb\) \((3,0)\) \(a\) 在 \(b\) 方向上的投影
方向向量 \(b\) 二维向量 材料给定 \((2,0)\) 投影所沿的方向

由表可见，\(c=\frac32\) 是一个标量系数，而 \(p=(3,0)\) 是由该系数缩放 \(b\) 后得到的向量。
