# 上传与有声链路测试材料

这里保留人工构造的输入样本，不含个人材料或 API Key。基础上传样本由 `evals.text` 使用；其中 PDF、DOCX 和解析失败样本还由 `evals.text_supplemental` 使用。`tts-二次方程.txt` 用于 `evals.narrated` 的 MiMo 配音及用户记忆全链路验收。

| 样本 | 用途 |
|---|---|
| 投影题.txt | UTF-8 中文纯文本 |
| 公式与表格.md | LaTeX、Markdown 表格与全文输入 |
| 中文题目.pdf | 中文文本型 PDF |
| 分页材料.pdf | 只选第 2 页，排除其他页的无关数据 |
| 段落与表格.docx | 段落和表格阅读顺序 |
| same_a/同名.txt、same_b/同名.txt | 同名原件、不同来源 ID |
| 缺少条件.txt、不可信指令.txt | 缺少必要题设与材料中的指令攻击 |
| 空白页.pdf、扫描页.pdf、题图.pdf | 空页、扫描文字与必要矢量题图 |
| 公式对象.docx、内嵌图片.docx | 尚不支持可靠解析的 Word 公式对象与图像 |
| 加密.pdf、损坏.pdf、空文件.txt | 无法处理或没有内容的输入 |
| 错误编码.txt、不支持.csv、扫描图片.png | 上传白名单和编码检查 |
| 超限.txt（本地生成） | 20 MiB + 1 字节，验证单文件大小上限 |
| tts-二次方程.txt | 因式分解、零乘积法则、求根公式和代回核验的有声讲解 |

## 重建与复用

从仓库根目录使用开发环境运行：

```powershell
python scripts/create_test_materials.py
```

脚本重建基础上传样本并生成不提交 Git 的 `超限.txt`；不会改写单独维护的 `tts-二次方程.txt`。PDF / DOCX 的元数据或序列化字节可能因生成时间和依赖版本变化，复测已有报告时应优先使用当轮保存的原件。脚本运行后会重写 `manifest.json`。

`manifest.json` 是当前磁盘样本的路径和字节大小清单，使用 `/` 分隔路径，不包括说明文件。未生成的超限文件不会出现在清单中。它不是跨平台固定摘要：文本换行或重新生成二进制样本后，应重新核对清单。

加密 PDF 的测试密码为 `test-password`，仅用于拒绝处理场景。公式对象或题图无法可靠读取的样本应在解析阶段进入待处理状态，不能据此声称模型理解了缺失内容。具体运行入口见 [evals 导航](../evals/README.md)，验收结论见[报告索引](../testresult/README.md)。
