# 开发计划

更新日期：2026年10月29日

本文集中维护实施顺序、完成标志和评测交付要求。能力设计分别由 [五份模块文档](index.md) 维护；长期记忆与个性化暂缓，近期聚焦 LLM、材料、回答和动画四项能力。

## 当前基线

0.1.0 已有纯文本输入、讲解规划、Manim 生成、执行纠错、VLM 检查、正式渲染、视频合成、单 Worker、本地网页、任务 API 与 CLI。自动化和真实渲染记录见 [MVP 验证记录](MVP验证记录.md)。

原第一版计划中的环境、单场景、执行纠错、VLM 循环、多场景和简单网页已有对应代码；这些开发任务的完成不等同于真实模型质量已经验证。真实调用成功率、画面质量和使用成本仍需固定样例实测。

当前尚无独立的材料、回答和视频资源，没有 `/api/v2`，也没有多协议适配、配音或学习记忆。本次调整仅迁移文档。

## 近期实施顺序

| 顺序 | 工作 | 完成标志 | 设计归属 |
|---|---|---|---|
| 1 | 使用固定纯文本样例验证当前文本与视觉模型；整理失败类别、时间和用量 | 得到可复现的真实模型基线，质量结论有证据 | LLM、动画 |
| 2 | 提取连接、模型绑定、配置快照和统一响应错误，先保留现有 Chat 协议兼容 | 自定义 Chat 端点可配置、可诊断，角色调用受预算约束 | LLM |
| 3 | 建立公共契约和结果仓储，先贯通纯文本 MaterialIR → Answer | 可独立获取、编辑与保存回答，不依赖渲染环境 | 材料、回答 |
| 4 | 将已有生成循环封装为消费 Answer 的视频模块，关联回答与场景步骤 | 同一回答可独立生成视频，视频失败无需重新回答 | 动画 |
| 5 | 增加独立 FileStore、原件上传、解析器注册与文本型 PDF、DOCX 路径，记录范围覆盖；回答先完整组装材料并检查总预算，按需要扩展原生文件能力测试 | 文件与直接文本产出相同契约，来源和处理范围可核对，超限不静默截断，回退与失败准确 | 材料、回答、LLM |
| 6 | 加入 v2 阶段 API 和页面编排，分别展示解析、回答、视频结果 | 只生成回答、编辑后转视频、独立重试均可完成，旧入口继续可用 | 各模块、总览 |

新协议按实际需要与小型请求响应样例逐一验证；无需等待所有厂商协议完成后再拆分业务模块。每项工作的具体待办和验收放在所属模块，不在本文重复维护字段与接口。

## 基础解耦后的扩展

配音、字幕、时间线和局部重建属于动画模块的后续工作，先验证讲稿与画面对应，再考虑片段复用。扫描件、复杂公式和手写、PPTX、音视频解析、长材料检索及工具按需读取，按对应格式和覆盖范围单独验收后接入；更复杂的前端或任务调度按实际需求评估。

长期记忆与个性化仅保留 [简要方向](05-长期记忆与个性化.md)，近期不排实施任务，也不先引入其数据库、检索和学习者接口。

## 评测与验证

开发过程中持续积累样例、输入版本、模型与提示词配置、预算、失败记录和产物。开发样例与测试样例分开，先定义完成条件、严重问题和指标分母，再运行评测；不能只统计成功视频。

| 对象 | 核对内容 | 证据 |
|---|---|---|
| LLM 接入 | 文本、结构化输出、图片和文件分别验证；鉴权、限流、截断等分类 | 固定合成样例、请求响应与脱敏调用记录 |
| 材料解析 | 格式覆盖、公式图示保留、来源定位、未知位置和回退 | 对照原件的解析结果及诊断 |
| 文本回答 | 题设与结论、来源、演示例子、修订一致性 | 固定材料与问题、规则及人工核对 |
| 动画生成 | 场景完整、中文公式、遮挡越界、候选一致性、失败状态 | [回归样例](mvp/输入与验收样例.md)、完整视频与检查记录 |
| 模块协作 | 独立回答、编辑转视频、单阶段重试、旧入口兼容 | API 与页面流程记录 |
| 资源与稳定性 | 耗时、调用次数、已知或估算用量、预算耗尽和中断行为 | 多次运行分布及失败类别 |

VLM 改进实验固定规划、模型和预算，比较仅执行纠错、四帧检查及后续关键步骤采样。内部 VLM 评分用于修订，最终质量同时使用可验证规则和独立人工评审。检查执行修复、视觉修订是否真实触发，以及新增检查带来的调用和时间开销。

约 10 个固定回归样例、其中至少 8 个在预算内完成且无严重问题，是旧计划的初始工程目标，尚非实测结果；门槛在真实基线后确定。当前没有实测成功率，也不能由渲染 smoke 测试推断模型质量。

未来重启记忆与个性化时再设计相应对照、消融和跨会话测试。模拟记录可验证机制，只有真实学习者实验才能支持学习效果结论。

## 交付要求与长期目标

近期交付包含可运行原型、源码与依赖锁定、配置模板、模块设计、接口和使用说明、演示材料、样例、验证记录及明确的未验证范围。公开材料不包含运行密钥和原始个人学习数据。

项目长期目标仍以原申报书为依据：形成带学习记忆的个性化视听讲解与反馈系统，交付系统和研究材料，并完成 CCF B 类及以上国际学术会议论文投稿或中国发明专利申请。投稿和申请不等同于录用和授权；这些长期成果要求不使暂缓模块成为近期依赖。
