# 当前开发版本运行与配置

**0.3.0 增补：** 当前已支持完整文字后接无声教学动画，默认网页可选双输出。安装使用 `uv sync --frozen --extra dev --extra animation`；新增 `lesson`、`video` 命令和 `/api/v2/videos`。下文的 0.2.0 文字行为保留为兼容说明，完整动画操作见[动画实现与本地运行](动画实现与本地运行.md)。

当前为独立的 0.2.0 文字版本。旧动画 MVP 的安装、Docker、generate、smoke 和旧 API 仅在[历史项目](../legacy_mvp/README.md)中使用，默认端口 8001；当前服务不加载这些模块。

## 启动与模型配置

```powershell
uv sync --frozen --extra dev
uv run manimagent serve
```

访问 http://127.0.0.1:8000。展开“LLM 配置”，填写 Chat Completions 接口、模型与密钥，可分别测试文本和结构化调用并选择回答／检查角色。保存立即用于新任务，已经接受的任务保持原快照。当前 DeepSeek 官方入口为 `https://api.deepseek.com`，模型为 `deepseek-flash`。详细凭据行为见[LLM 界面配置](LLM界面配置.md)。

初始配置也可通过 `.env` 的 MANIMAGENT_TEXT_BASE_URL、MANIMAGENT_TEXT_MODEL、MANIMAGENT_TEXT_API_KEY 提供。`.env` 不覆盖已有进程环境变量；界面配置覆盖新文字任务的对应设置。复制示例时不要覆盖已存在的本地配置或凭据。

```powershell
uv run manimagent doctor
uv run manimagent answer --question "给定 a=(3,2)、b=(2,0)，求 a 在 b 方向的投影" --file notes.pdf --output answer.md
```

当前 CLI 只提供 serve、answer、doctor；不再接受历史 generate、smoke 或 --text-only。`--file` 可重复，`--text` 提供补充材料；命令行对文件默认全文解析，PDF 范围请使用网页或 API。`--config` 放在子命令前，配置中相对路径按该文件目录解析。

## 文件与回答

问题必填，可添加多文件和粘贴材料。PDF 范围从 1 开始且包含两端，同名文件依靠独立 ID 区分。短材料按全文组装；发送模型的来源同时包含文件名、ID 与块位置。答案以原始 Markdown 保存，网页仅派生展示，下载与版本正文一致。

默认支持 UTF-8 TXT／Markdown、文本型 PDF 和普通 DOCX 段落／表格。扫描页、题图、未识别公式对象或嵌入图片会明确进入待核对；DOCX 的上下标（含使用的样式及继承）、特殊符号也会进入待核对，请改用明确的文本或 LaTeX。空文本、损坏／加密文件和缺少条件需要补充输入。不支持图片、PPTX、音视频、OCR 或原生文档上传到提供商。超预算不截断，尚未完整的结果不发布为 Answer。

当前所有模型配置使用 Chat Completions 协议；可给回答和检查绑定不同配置，不自动转换 Responses、Anthropic Messages 或 Gemini 原生协议。2026-10-30 的[真实复测](../testresult/review-20261030/真实测试报告.md)使用同一 DeepSeek 服务验证多配置，不代表已实测多个厂商。默认 system prompt 为通用学习助手，仅接收本次指令与显式指定材料，不注入用户历史或长期记忆。

## 数据与限额

默认 runs_dir 为 `runs/current`，private_dir 为 `runs_dir/private`。原件、材料、回答、任务和配置均保存在该私有目录。API Key 与非秘密配置分开保存；Windows 使用当前用户 DPAPI 加密。该目录不提交 Git 或进入发布包。

默认单文件 20 MiB、单次 PDF 最多 100 页、解析文字共 200000 字符、DOCX 展开 50 MiB／2000 条目、单次解析 60 秒；回答预算默认 24000 token（含输出预留），与模型 context_window 取较小值。配置模板为根目录 config.example.yaml，不含任何动画参数；旧动画配置不能直接混入当前 Settings。

普通回答不发送 JSON response_format；检查报告根据模型 json_mode 使用 JSON 或提示词约束与校验。token_parameter 支持 max_tokens／max_completion_tokens；generate_url 是完整操作地址，否则在 base_url 后追加 /chat/completions。

## 测试与运行约束

```powershell
uv run python -m pytest -q
uv run ruff check src tests scripts
uv run ruff format --check src tests scripts
```

自动化测试位于重建后的 tests/unit 和 tests/integration，使用受控传输；真实 DeepSeek 文件测试为显式脚本，不在 CI 自动消费密钥或用量。材料和输出分别位于 testmaterial 与 testresult，本轮结果见[测试报告](../testresult/测试报告.md)。历史 MVP 测试在自己的目录及虚拟环境中执行。

当前使用单个服务进程与单个文字 Worker；不要对同一 private_dir 同时运行多个写入服务或 answer CLI。服务重启不自动重跑任务，未完成尝试标为 interrupted；已登记的完整回答继续可读。系统仍面向本机单用户，没有公开部署所需的认证与租户隔离。
