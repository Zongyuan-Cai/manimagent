# 项目文档

当前 0.3.1 已实现完整文字链路、整体切分与分块无声动画。实际运行见[动画实现与本地运行](动画实现与本地运行.md)。TTS、个性化和长期记忆暂缓；旁白和 cue 已进入估计时间线，尚未进行真实音频对齐。
