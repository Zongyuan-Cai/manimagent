# 文档导航

本目录保留三类文档：`current/` 说明当前使用与实现，`design/` 维护架构决策和验收约束，`research/` 保存带日期的研究依据与实验方案。当前服务为本机单用户的完整文字、可配音动画与可选用户记忆。

MiMo TTS 已接入；开启后使用 `time_source=audio_measured`，节拍内部 `cue_time_source=estimated`，不代表词级精确同步。可选用户记忆支持只读或读取并后台学习：受理时冻结已有记忆，输出结束并发布 Answer 后再提取新偏好，用于后续任务。后台队列提供有界重试、取消、重启恢复、独立用量与自动清理；普通纠正保留层级。文字与视频共享审计快照，模型使用分角色稳定投影；缓存用量区分未知、零与部分回报，已有小样本真实命中记录，尚不能证明总体性能收益。工程行为见下列 current 文档；[研究方案](research/个性化记忆与投稿研究方案.md)分别维护记忆和音画对齐两个方向。

记忆目录提供 Markdown 索引、独立条目及实际请求的注入记录，支持显式版本校验导入；SQLite 继续负责提交与后台状态。文件阅读、编辑冲突、同步失败及历史快照边界统一见[用户记忆与个性化](current/用户记忆与个性化.md#记忆文件与受控编辑)。

首次使用先在网页配置核心 API；需要图片／扫描页时选择支持视觉的材料读取模型，需要配音时再独立配置和试听 MiMo TTS。附件支持范围已扩展至代码、结构化数据、Office 与静态图片，但不执行代码／宏或重算表格；格式细节与未覆盖内容见运行说明。
