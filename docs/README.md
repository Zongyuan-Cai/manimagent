# 文档导航

更新：2026-11-13。`current/` 说明当前代码和使用方式；`design/` 维护目标架构与产品约束；`research/` 保存注明版本的研究依据与实验方案。历史评测在 `testresult/`，不能替代当前或未来版本验收。
