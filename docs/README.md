## 阅读顺序

1. 阅读[总体开发计划](总体开发计划.md)，了解完整目标和六个总体阶段。
2. 阅读对应的阶段设计，确认输入输出、模块边界、依赖和验收方式。
3. 开始第一阶段时，阅读[第一版 MVP 设计](MVP设计.md)，按纯文本入口、状态和接口规则实现；样例见[输入与验收样例](mvp/输入与验收样例.md)。
4. 需要技术背景时查阅[技术栈与整体设计](技术栈与整体设计.md)。
5. 参考[第一阶段任务清单](第一版开发计划.md)继续细化实现任务。

## 文档职责

总体开发计划维护项目阶段及其交付结果。阶段设计维护各阶段的范围、数据流、主要模块和验收情形。第一版 MVP 设计给出第一阶段的具体实施基线；技术栈与整体设计提供跨阶段的技术讨论，第一阶段任务清单记录更细的实施拆分。

阶段范围发生变化时，先更新总体计划与相应阶段设计，再同步修改技术说明与任务清单。技术候选在对应阶段经过验证后才成为实际依赖。
