更新日期：2026年10月17日

## 阅读顺序

1. 阅读[总体开发计划](总体开发计划.md)，了解完整目标和六个总体阶段。
2. 阅读对应的阶段设计，确认输入输出、模块边界、依赖和验收方式。
3. 需要技术背景时查阅[技术栈与整体设计](技术栈与整体设计.md)。
4. 开始第一阶段时，参考[第一阶段任务清单](第一版开发计划.md)继续细化实现任务。

## 文档职责

总体开发计划维护项目阶段及其交付结果。阶段设计维护各阶段的范围、数据流、主要模块和验收情形。技术栈与整体设计提供跨阶段的技术讨论，第一阶段任务清单记录更细的实施拆分。

阶段范围发生变化时，先更新总体计划与相应阶段设计，再同步修改技术说明与任务清单。技术候选在对应阶段经过验证后才成为实际依赖。

## 设计状态与后续工作

当前尚未验证本机运行环境、模型组合、生成成功率或长期记忆效果。近期工作是按第一阶段设计复现基本生成和检查流程，取得可比较的基线；后续阶段暂保留接口边界，不提前建设全部服务。

申报书作为需求依据，文档仅整理其项目目标与成果要求。原始申报文件、学习者原始数据和运行密钥不作为本次文档提交的内容。
