# 文档导航

本目录保留三类文档：`current/` 说明当前使用与实现，`design/` 维护架构决策和验收约束，`research/` 保存带日期的研究依据与实验方案。当前服务为本机单用户的完整文字、可配音动画与可选用户记忆。

MiMo TTS 已接入；开启后使用 `time_source=audio_measured`，节拍内部 `cue_time_source=estimated`，不代表词级精确同步。可选用户记忆提供生成、短期／深层迁移、确认、纠正与清理，并将同一快照传给文字与视频。工程行为见下列 current 文档；[研究方案](research/个性化记忆与投稿研究方案.md)分别维护记忆和音画对齐两个方向。
