# 文档导航

本目录按用途分为 `current/`、`design/`、`research/`、`archive/`。当前服务仍是 0.3.1 的本机单用户、完整文字与分块无声动画；代码已按业务边界重新组织。目录重组不等于新增功能或生产验收通过。

TTS、个性化与长期记忆暂缓。旁白稿、语义 cue 与画面事件现在就共用时间线；当前 `time_source=estimated`，实际音画同步须待真实音频接入后验证。
