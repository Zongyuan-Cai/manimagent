# 第四阶段 记忆驱动的个性化规划

状态：设计草案

本阶段将学习记忆接入教学规划，使学习者的知识基础、历史错误和反馈能够改变最终讲解。依赖已有的记忆检索与视听生成能力。

## 目标与边界

根据当前材料与相关学习状态，决定是否补充先修知识、讲解重点、推导深度、步骤顺序和视觉表达。每项主要调整应有可追溯的依据。

先验证有限知识领域中的可解释差异，不预设需要模型训练或复杂的教学策略学习。完整用户交互在第五阶段集成。

## 输入与输出

| 类型 | 内容 |
|---|---|
| 输入 | MaterialIR、本次目标、MemorySnapshot、相关先修关系 |
| 中间结果 | LearnerContext、教学调整提案、决策证据与约束检查结果 |
| 输出 | 个性化 LessonPlan、SceneSpec、讲稿及对应视听结果 |

## 核心流程

识别目标知识点 → 检索相关记忆和先修状态 → 构建有限教学上下文 → 规划调整 → 核对证据与内容约束 → 调用已有生成流程。

## 模块与关键设计

| 模块 | 职责 |
|---|---|
| ContextBuilder | 组织与当前任务有关的状态、历史困难与偏好 |
| PersonalizationPlanner | 选择补充内容、重点、深度、顺序和视觉方式 |
| PlanValidator | 检查证据是否有效、内容条件是否保留、规划是否可执行 |
| PlanExporter | 输出已有生成模块可以消费的场景和步骤结构 |

每项决策记录 decision、concept_id、evidence_ids 和 planned_effect，并引用统一的记忆快照。生成与检查使用同一份规划版本，防止新事件改变正在生成的评价标准。

证据不足时采用通用讲解，必要时建议后续诊断，而不假定学生存在某种困难。明确的本次讲解要求应被规划考虑；与推断偏好冲突时记录取舍依据。

个性化规划不能改变定义和定理条件。VLM 检查可以确认补充步骤是否呈现；个性化是否合理需要独立评审，学习效果需要额外证据。

## 示例

相同材料介绍特征向量。对矩阵作用理解不足的学习者，先补充向量与网格变换；对基础扎实的学习者，缩短背景，展开相关方程与推导。两份规划保留共同的核心定义，差异关联各自学习证据。

## 验收与交付

针对同一材料准备不同知识状态及一个无相关历史的情形，比较规划与最终视频。检查差异是否有必要、是否有证据、是否真正呈现，并覆盖证据矛盾、历史被纠正和本次要求变化等情形。

交付教学上下文、规划与验证接口，成对个性化样例、决策记录及初步对照结果。规划仍通过已有 SceneSpec 和讲解步骤进入生成流程。
