# 第六阶段 评测优化与成果交付

状态：设计草案

本阶段汇总开发中持续积累的样例与记录，验证系统完整性及记忆驱动规划的作用，完成优化、文档和研究成果提交。

## 目标与边界

评测回答三个问题：系统能否稳定运行，记忆能否被正确保存与使用，个性化决策是否合理并落实到讲解。具备真实学习者实验条件时，再研究学习效果。

申报书要求交付可运行原型及支撑材料，并完成 CCF B 类及以上国际学术会议论文投稿，或中国发明专利申请。投稿与申请不等同于录用与授权。

## 输入与输出

| 类型 | 内容 |
|---|---|
| 输入 | 固定系统版本、测试材料、模拟学习历史、评审规则、实验配置与运行记录 |
| 输出 | 测试与对照结果、问题修复、可复现实验包、系统交付材料、研究成果提交凭证 |

## 评测设计

| 评测对象 | 主要检查 | 记录或对照 |
|---|---|---|
| 生成完整性 | 是否完成所有场景，是否出现严重内容或画面问题 | 固定输入与预算、人工视频检查、失败类别 |
| VLM 循环 | 是否改善画面问题，代价是否合理 | 固定规划下比较仅执行纠错、加入视觉检查；采样改进单独消融 |
| 学习记忆 | 状态是否有依据，矛盾与纠正是否正确处理 | 连续事件脚本、跨会话与隔离检查 |
| 个性化规划 | 差异是否有必要、有证据并被执行 | 无记忆与有记忆对照；按研究问题增加摘要或向量记忆对照 |
| 音画与局部修改 | 步骤是否对应，重建是否覆盖正确依赖 | 时间线检查、完整播放、修改前后产物与耗时 |
| 资源与稳定性 | 耗时、调用次数、恢复和失败行为 | 多次运行分布、错误类型、可获取的调用使用量 |

## 实验约束

先定义完成条件、严重问题和各指标分母，再运行评测。开发样例与测试材料分开，模型、提示词、预算和记忆快照按实验固定。不同学习者的历史与数据严格区分。

针对 VLM 的实验固定教学规划与记忆；针对学习记忆的实验固定生成流程及可用上下文预算。通用生成经验库在对照之间统一关闭或使用相同冻结版本，避免跨组积累。

内部 VLM 评分用于生成修订，最终质量另有独立人工评审与可验证规则。记录未完成检查、生成失败和被排除样例的原因，不能只报告成功视频。

模拟记录验证机制，专家评审验证内容与个性化合理性。只有实际开展学习者实验，才报告相应学习效果；可按条件采用前测、后测和延迟测验。

## 优化与交付

依据实际瓶颈改进检索、规划、提示词、缓存、场景划分或调度。每项主要优化使用相同配置重新比较，明确改善了什么及其代价。

交付包含系统源码、依赖与配置说明、接口说明、部署与使用文档、演示材料、测试报告、实验配置和结题材料。原始个人学习数据与运行密钥不进入公开实验包。

根据实际方法和验证结果组织论文或专利材料，完成申报书要求的提交并保留凭证。成果形式和作者、发明人等信息按申报书及实际贡献确定。

## 验收

按说明在独立环境复现核心演示和主要实验；检查需求对应的测试证据、失败记录和使用限制；确认系统材料与研究提交材料齐全。未完成的真实学习效果验证如实列为限制。
