# 完整回答与版本设计

更新：2026-11-06。本文维护正文、来源、检查与视频交接的一致性规则；API 和操作见[能力与接口](../current/能力与接口.md)。

## 正文是独立产物

回答模块从完整材料、本次要求和可选用户记忆快照生成 Markdown。正文独立可读、可下载，不能为了分镜而删减推理，也不能依赖动画或语音服务可用才能生成。

主回答使用普通文本输出；来源索引、标题与步骤由同一 Markdown 派生。当前可使用单个无损全文步骤，视频侧另按原文范围建立细粒度 TeachingUnit；步骤数量不代表推理覆盖率。

## 一次生成

```text
所选完整材料 + 当前 instruction
  → 可选用户记忆提取、选择并冻结快照
  → 按回答模型检查完整上下文预算
  → 输出 Markdown 候选
  → 来源校验与可配置内容检查
  → 保存不可变 Answer
  → 页面可读；both 模式继续视频
```

提取记忆不读取教材、答案或渲染日志。记忆在当前提取之后、文字生成之前冻结，作为有界数据影响表达，当前要求优先。关闭记忆时不依赖记忆提取服务；具体生命周期见[分层用户记忆](05-长期记忆与个性化.md)。

预算不足不静默截断材料；输出截断、缺少必要条件或必要检查未完成时保留候选诊断，不将其发布为完整成功 Answer。合法引用只说明标识有效，内容检查仍需对照完整材料、用户要求和候选正文。

## 修订与视频交接

| 操作 | 必须保持的关系 |
|---|---|
| 人工编辑正文 | 生成新 answer_id，保留 derived_from_answer_id，重新派生索引并校验来源 |
| 人工编辑后的记忆 | 继承原 Answer 的快照，不重新读取当前活动记忆 |
| 生成或续跑视频 | 使用指定 Answer ID/hash 与其快照，不重新调用 writer |
| 内容检查回执复用 | 正文摘要、检查策略与检查模型配置均匹配 |
| 未检查的修订版进入视频 | 先补内容检查，成本计入视频预算 |
| 动画发现正文错误 | 返回定位；需要修订正文时显式生成新版本 |
| 视频失败 | 保留全文与阶段错误；双输出为 partial |

旧视频继续指向旧 Answer。页面不能把旧异步响应或旧成片挂到新正文上；ID 与 hash 均需核对。

## 后续扩展

检索、按块选择和工具读取尚未接入。引入它们时需记录实际上下文、遗漏范围与依赖补齐，不能用相似度分数替代题设完整性。模型自动修订如成为产品功能，也必须沿用不可变版本、来源校验、预算与明确用量规则。

当前模型检查不能视为形式证明。真实数学正确性、个性化遵循和人工可读性需要独立评测；无付费模型的确定性测试主要验证状态、版本、来源和预算。
