# 动画生成设计

更新：2026-11-06。当前已实现固定 Answer、分块计划、可信 Manim 模板、可选 MiMo 配音与成片核验。安装、API、模板范围和实际限额见[动画实现](../current/动画实现与本地运行.md)，本文维护流程决策与扩展边界。

## 内容先定版，时间后解析

动画把既定解答讲清楚，可以分屏、拆步骤、安排观察顺序，但不能重新解题或静默改变条件与结论。教学单元定位 Answer 的 Unicode 原文范围，并保存摘要；所有场景必须承接必要单元。

旁白、屏幕短句、公式、图形状态和语义 cue 在同一节拍中建立联系。先明确“讲到什么时，哪个对象出现或高亮”，再由程序解析时间。对象指向正确、事件关系正确和音频时间正确是不同的检查问题。

```text
固定 Answer ID/hash、检查回执与记忆快照
  → 整体教学规划与单元覆盖
  → 逐场景生成声明式节拍
  → 估计时间、规则预检、排版与计划内容检查
  → 可选 MiMo 合成及按实测时长重排
  → 可信模板渲染、事件与时长核验
  → 合成、可选音轨封装、完整解码
  → 发布同版 VideoResult
```

逻辑阶段不等于每阶段必须增加一个模型。当前模型角色为 planner、scene_generator、plan_checker；没有执行模型生成 Python 的 scene_coder，也没有视觉模型检查。

## 场景与节拍

当前场景自包含，跨场景共享符号和颜色约定，不依赖上一个 Python Scene 的隐式状态。每拍应只有一个主要认知变化，提供实际上屏解释、公式、必要图形与可朗读旁白。对齐不能只比较总长，还要检查 cue 是否指向正确对象、解释时对象是否可见。

首版 120～360 秒是交付范围，具体长度应由需要解释的内容决定。简单题不靠无关例子、重复动作或长片尾补足时间；复杂题超出范围时提示拆分，不交付只覆盖前半题的成功结果。

模型根据受众、推理依赖、公式密度和视觉复杂度提供规划理由；难度标签不直接映射分钟数。记忆只在固定 Answer 内容边界内影响教学组织，当前模板不支持任意视觉风格。

## 两种时间来源

| 模式 | 时间依据 | 不能据此声称 |
|---|---|---|
| 无声 | 旁白估时、动作窗口、屏幕稳定阅读要求；time_source=estimated | 真实音画同步 |
| MiMo 配音 | 同版 WAV 的节拍实测长度，并保留必要阅读窗口；time_source=audio_measured | 逐词或对象状态已精确对齐 |

有声模式的 cue_time_source 仍为 estimated。语音过长时延长节拍；超过单拍或全片上限就失败，不能截断旁白、加速音频或删推理。时间需按帧对齐，计划、音频和实际渲染事件共同核验。配置和结果字段见[MiMo语音](../current/MiMo语音与验收.md)。

## 检查与有限修复

检查分开处理正文语义、计划覆盖、模板几何和最终媒体。必要单元 fail／unknown 均阻止发布，不用平均分抵消严重问题。计划要求 revise 时必须定位可修复场景；上游答案错误不能通过美化场景解决。

修复共享有限调用和父 deadline。每次改动都重做受影响的预检与最终统一内容检查，取得合格候选即可停止。显式续跑复用同版分块，重新排程、检查和渲染；旧成片不跨候选自动复用，续跑成本不回填第一次成功率。
