# 动画生成设计

更新：2026-11-13。状态：**目标设计，尚未整体实现**。本文落实[固定教学流水线架构](00-固定教学流水线架构.md)中的视频合同、可信执行与失败边界。当前模板、配置和已实现接口见[动画实现](../current/动画实现与本地运行.md)；本文新增的类型化数学图形、语义配色和阶段产物不能当作现有 renderer 已支持的能力。

## 固定正文与视频交接

视频以指定版本的 `VerifiedAnswer` 为唯一教学事实源。它可以拆屏、安排观察顺序、组织示意与旁白，但不能重新解题、修改题设或删掉必要推理。正文的教学单元、来源和依赖在[文本回答设计](03-文本回答生成.md)中定义，视频不另维护一份可漂移的摘要答案。

本次 `EffectiveProfile` 在进入生成阶段前已经固定。视频读取其中适用的 `TeachingSpec`、`VisualSpec`，不重新查询记忆库，也不在每个场景再次解释用户偏好。当前明确要求无法由已支持能力实现时，尽早返回具体不支持项；历史软偏好不适用时记录原因，不把“已注入”写成“已执行”。

## 固定阶段合同

| 阶段 | 输入 | 输出与放行条件 |
|---|---|---|
| 视频大纲 | VerifiedAnswer、教学参数、视频目标与能力合同 | `VideoOutline`；覆盖必要教学单元，场景与总预算可核对 |
| 场景生成 | 当前场景规格、相关单元及依赖闭包、全局符号、VisualSpec | `ScenePlan`；包含屏幕内容、数学图形、旁白与 cue |
| 场景检查与编译 | ScenePlan、支持的图形与布局规则 | 结构、语义引用、几何、布局和预计时间均满足合同 |
| 整体检查 | VerifiedAnswer、全部场景及检查凭据 | 单元覆盖、数学含义、跨场景符号与教学次序通过 |
| 可选 TTS 与排时 | 已核对旁白、语音参数、必要阅读窗口 | 音频与实测时长；重排后仍满足节拍和全片约束 |
| 可信渲染与媒体核验 | 已核对计划、VisualSpec、必要音频 | 最终媒体、事件记录及核验凭据；通过后发布 |

阶段边界不等于每一步都新增模型调用。引用、预算、参数、编译、时间及媒体检查由代码执行；语义生成和内容核对使用明确的模型阶段。场景自包含，跨场景共享显式符号约定，不依赖上一个 Python Scene 的隐式状态。

每拍包含一个主要认知变化。屏幕短句、公式、图形状态、旁白与 cue 必须指向同一内容；对象正确、对象可见、事件顺序正确与音频时间正确分别检查，不能只比较总长。

## 能力定义与类型化数学图形

Rendering 维护版本化能力定义，包括支持的图形类型、参数范围、数学表达式子集、样式、空间和时间限制。模型可见说明、输出 schema、编译器和校验器必须使用同版能力。提示词不得宣称编译器没有实现的表达能力。

| 数学图形类型 | 可信编译器的职责 |
|---|---|
| 离散点集 | 根据点坐标生成独立点；默认不连线，不能暗示连续函数 |
| 函数曲线 | 按受支持的函数表达式、定义域与采样规则生成；保持定义域和不连续点语义 |
| 割线 | 根据指定的两个有效点计算与绘制，检查点及对象引用 |
| 切线 | 根据受支持函数、切点与对应计算生成；不可微或超出支持范围时报错 |
| 数轴、矩阵等 | 使用各自明确的数据合同、标注和可见范围 |

这些类型是目标能力，必须逐项实现和验证后才对模型开放。表达式由受限数学解析器处理，不执行模型提供的任意 Python。缺少某一图型能力时不能以外观相近的折线或示意替代必要数学对象；输出无图模式也不能成为删除必要图形的兜底。

类型、参数和几何校验不能独立证明完整教学语义正确，整体内容检查仍需对照 VerifiedAnswer。必要语义项不确定时阻止发布。

## 视觉参数必须实际执行

场景模型为对象选择主对象、对比、强调、辅助等语义角色，最终颜色由 VisualSpec 映射。模型不再任意指定具体颜色来覆盖已接受的用户主题。字号与动画强度同样转换为渲染器支持的参数，并在编译、布局和实际事件中核对。

应用记录区分用户请求、有效值、实际执行值和覆盖原因。颜色、对象边界等可确定性检查；“直观”“易懂”“节奏合适”等教学要求仍需内容评估，不能声称已获得同等硬保证。

主题变更可能影响对比度、标注或布局，因此需要重新执行相应检查。无法满足当前硬要求时明确失败或要求调整，不能换成默认样式后继续声明偏好已满足。

## 时间与交付合同

目标成片仍为 120～360 秒、1280×720、30 fps，具体长度由必要教学内容决定。简单题不靠空等、重复动作或无关例子补足时长；复杂题超出范围时要求拆分，不把只覆盖前半题的片段作为完整视频。

| 模式 | 时间依据 | 不能据此声称 |
|---|---|---|
| 无声 | 旁白估时、动作窗口和稳定阅读要求；`time_source=estimated` | 已测得真实音画同步 |
| MiMo 配音 | 同版音频的节拍实测长度与必要阅读窗口；`time_source=audio_measured` | 已实现词级或对象状态精确对齐 |

现有有声路径的 `cue_time_source` 仍为 `estimated`，本次目标设计不自动改变这一事实。语音过长时重排节拍并重检；超出单拍或全片上限则失败，不能截断旁白、加速音频或删推理。时间按帧对齐，计划、音频与实际事件共同核验。当前音频行为见[MiMo 语音](../current/MiMo语音与验收.md)，生产口径见[时长与生产验收](动画时长与生产验收.md)。

## 修复、发布与恢复

每个阶段按“输入校验 → 生成或执行 → 输出校验 → 提交产物”推进。只有已提交产物能成为下游输入；失败候选保留诊断，不能伪装成检查通过的中间结果。局部修复必须定位场景或对象，并包含旧候选与具体错误，消耗同一父预算；取得合格候选即停止。

必要覆盖、语义、几何和媒体检查的 fail／unknown 均阻止对应视频发布，不用平均分抵消严重问题。视频失败时保留已发布正文，双输出明确为部分完成；用户请求有声视频而 TTS 失败时，不能发布静音视频冒充完整成功。

恢复沿显式产物依赖进行：

- 正文内容或教学要求改变：建立新版本，重新核对正文及受影响的视频阶段。
- 颜色或视觉参数改变：重新编译并执行受影响的布局、渲染与媒体检查。
- 声音改变：重新配音、排时与受时间变化影响的渲染或封装。
- 网络或进程中断：从尚未提交的阶段恢复，已提交产物按当前合同验证后复用。

产物绑定输入内容、schema、能力、编译与检查版本。模型配置记录生成来源；模型名称变化本身不等于产物失效。检查标准改变时旧凭据失效，复用必须补相应检查。所有重试、修复和续跑成本单列，不回填首次完成率。

## 验收与边界

重点验证离散点不误连线、函数不被错误近似替换、割线与切线关系、语义色实际执行、单元依赖与必要覆盖、可读时间以及媒体完整解码。关键帧采样不能替代完整成片与过渡过程复核。

本目标不引入任意 Python 后端、动态工具调度、自动会话压缩或生成器在线自改提示词。词级强制对齐、字幕、三维、VLM 检查、跨任务成片缓存与场景并发仍需独立设计、能力开放和验证。

提示词职责见[Prompt 与检查规范](动画Prompt与检查规范.md)。音画研究与历史证据见[研究方案](../research/个性化记忆与投稿研究方案.md)，不能把文档更新当作新能力验收通过。
