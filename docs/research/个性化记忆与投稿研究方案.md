# 记忆与音画对齐：两个独立研究方向

更新：2026-11-06。本文记录研究问题与验证路线，不代表论文创新性已经确认，也不将工程功能完成等同于论文实验完成。当前使用说明见[用户记忆](../current/用户记忆与个性化.md)、[MiMo语音](../current/MiMo语音与验收.md)。

## 项目与已有工作的关系

[ManimAgent: Self-Evolving Multimodal Agents for Visual Education](https://arxiv.org/abs/2606.30296) 是项目作者本人的已有工作。早期文档将其误写为外部同名竞争工作、建议因重名另起题名，该建议撤回。后续论文应清楚说明与作者已有论文的增量，避免把已经发表的生成与修复记忆再次包装为新贡献。

作者当前选择两条独立路线：用户记忆的生成、跨层迁移和清理；数学讲解中的音画对齐。两条路线可以共用项目作为实验平台，但不要求先合成一个大型个性化学习系统，也不以大量真人数据采集为启动前提。

## 方向一：用户记忆生命周期

### 研究对象

维护一套用户记忆，用户画像、视觉偏好、讲解偏好等只是字段。层级表示稳定程度；近期交互产生短期条目，独立重复证据或明确确认支持进入深层。核心是三个决策：什么进入记忆、何时在层间迁移、什么需要清理。

本方向不生成通用修复经验，不将历史交互持续合并为经验摘要，也不把字段划分本身作为论文贡献。当前工程首版使用确定性规则：有原句的候选、独立会话计数、可见管理入口、过期及容量限制、固定生成快照。该实现是可复现基线，还不是学习型策略或已证明优于已有方法的新算法。

### 需要对比的工作

| 原始工作 | 与本方向相关的已有能力 | 对研究设计的要求 |
|---|---|---|
| [MemoryOS，EMNLP 2025](https://aclanthology.org/2025.emnlp-main.1318/) | 短期、中期、长期个人记忆及动态更新 | 不能仅以增加层级或迁移流程作为新意 |
| [MemoryBank](https://arxiv.org/abs/2305.10250) | 根据时间与重要性强化、遗忘长期记忆 | 不能仅以时间衰减或遗忘曲线作为新意 |
| [Auto-Dreamer](https://arxiv.org/abs/2605.20616) | 将快速获取与跨会话离线巩固分开，学习巩固策略 | 快慢过程和巩固调度已有研究；本方向需明确用户信息状态判断的增量 |
| [Useful Memories Become Faulty When Continuously Updated by LLMs](https://arxiv.org/abs/2605.12978) | 在其评测环境中发现持续巩固可能降低记忆效用，保留原始经历具有竞争力 | 保留可核对依据，不能预设更深或更抽象一定更好 |
| [Memora](https://arxiv.org/abs/2604.20006) | 评估随用户情况变化的记忆，以及过时、无效记忆的误用 | 应使用外部评测补充自建案例，并明确清理对最终回答的影响 |
| [LongMemEval](https://arxiv.org/abs/2410.10813) | 信息抽取、多会话推理、时间推理、知识更新与拒答评测 | 不能只测静态检索命中率 |

以上是相关工作线索，尚未完成统一预算下的代码复现与完整新颖性审查。

### 候选核心假设

在相同存储和模型调用预算下，依据独立证据区分“临时要求、稳定属性、已经变化的信息”，联合控制生成、迁移和清理，可能比固定次数晋升、固定时间遗忘更少误记、更快适应真实变化。

这一假设需要实际机制和对照实验支持。可先分析同一会话重复、模型复述、自我强化、任务范围变化等错误来源，再决定是否需要概率模型、变化点判断或可学习策略；不为方法复杂度而提前添加训练和多智能体模块。

### 无需大量真人采集的首轮评测

预设隐藏的稳定偏好、临时例外、噪声、范围与变化时点，生成多会话表达；方法只看到用户表达，评分器持有独立的隐藏状态。划分应覆盖未见过的用户状态组合和表达方式，不能只更换同一模板中的词语。

| 评测环节 | 指标与对照 |
|---|---|
| 生成 | 错误写入率、遗漏率、原句依据正确性；检查题目内容是否被误认为用户事实 |
| 迁移 | 临时信息误晋升率、稳定信息识别率；固定同一来源重复十次与十个独立会话分别比较 |
| 更新与清理 | 用户变化后的修正延迟、过时记忆使用率、误删仍有效记忆的比例 |
| 下游生成 | 当前要求和有效偏好遵守率、数学内容正确性、实际成本；文字与视频分别评估 |
| 资源 | 活动条目、存储、上下文长度、全部提取及管理调用量；清理成本也计入 |

至少比较：无记忆、短期窗口、平坦记忆、频次晋升与时间清理、完整方法；逐项移除证据去重、迁移与清理。相同模型、上下文和调用预算下比较，所有失败保留。可用 Memora、LongMemEval 检验外部适用性，受控模拟只能支持记忆管理和个性化生成的结论，不能证明真人学习收益。

## 方向二：数学对象状态感知的音画对齐

### 工程基础与边界

当前 MiMo TTS 已提供真实音频，按实测旁白时长安排节拍；节拍内高亮位置仍按文本比例估计。词级强制对齐、字幕及语义状态对齐尚未实现。现有真实有声链路成功是工程基础，不能直接作为精确音画对齐的研究结果。

[Manim Voiceover](https://voiceover.manim.community/en/stable/quickstart.html) 已支持音频时长和词语书签同步；[Data Player](https://virtual.ieeevis.org/year/2023/paper_v-full-1049.html) 已研究旁白与视觉对象的语义关联及同步约束。因此，接 TTS、使用时间戳或添加统一时间线不足以单独构成贡献。

### 候选研究问题

同一个符号或向量会在推导过程中移动、变形、分解或消失。即使语词时间戳正确，讲解也可能指向错误版本的对象。候选方向是绑定“旁白片段—数学对象—当前状态”，验证对象在对应讲解窗口是否存在、动作是否完成，并在语速或局部推导变化后修复受影响事件。

这仍是待验证的新颖性假设。需要进一步和语义关联、约束调度及可执行动画生成方法对比，不能仅因场景换成数学就认为是新方法。

### 数据与评测

以可执行数学或算法轨迹构建状态真值，例如向量变换、代数步骤或排序过程。真值生成器与被测方法分离，按任务和模板家族划分；语音分句拼接只能提供句段级时间真值，不能声称自然连续语音的逐词真值。

对照当前比例估时、强制对齐加自动书签、直接 LLM 时间线、语义关联加调度，以及理想对象绑定上界。指标包括对象／状态绑定、允许时间窗口内的事件比例、状态和顺序违规、可见性覆盖、语速／停顿／改写扰动后的稳健性、修复范围与成本。

可以增加少量独立核查的自然旁白样例提高外部有效性；不要求先开展大规模学生实验。也不能由相同对齐器生成真值并给自己评分。

## 当前实施顺序与投稿判断

先完善可用项目：有声输出、用户记忆规则、管理入口、版本快照、失败提示、测试和文档。工程交付分别记录在 [TTS 报告](../../testresult/tts-20261105/报告.md) 与[记忆报告](../../testresult/memory-20261106/报告.md)。

之后每条研究路线各自完成问题定义、最接近工作复现、失败集、方法及独立评测，再选择主投方向。音画对齐可按多媒体／可视化方法论文组织；用户记忆可按 AI／NLP 的持续交互记忆方法组织。CCF B 及以上是目标，不是当前功能组合自然满足的门槛。

会议级别、征稿主题与截止日期应在实际投稿决策时重新核对官方页面，不沿用旧目录或已经过期的时间表。现阶段不把真人学习效果、跨设备画像或生成器经验积累加入工程必需范围。
