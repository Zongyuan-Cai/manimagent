# LLM 界面配置

日期：2026年10月29日。

启动 `uv run manimagent serve`，打开 http://127.0.0.1:8000，展开“LLM 配置”。如果回答模型尚未配置，面板会自动展开。网页配置只管理当前文字链路；旧动画入口继续使用原 YAML／环境配置。

## 使用方法

1. 填写 API 根地址（包含服务的版本前缀，例如 `https://gateway.example/v1`）和实际模型名称。
2. 选择 Bearer API Key、自定义密钥请求头或无鉴权。需要鉴权时输入 API Key；已配置密钥时留空会保留原值。
3. 可分别点击“测试文本调用”和“测试结构化输出”。测试使用当前表单的草稿，不保存配置；会向指定接口发送简短请求，可能产生少量用量。
4. 选择回答模型和内容检查模型，按需开启内容检查，点击“保存并应用”。新任务立即生效，无需重启；已经接受的任务继续使用原配置与密钥引用。

“新增模型”可以为另一个接口或模型建立配置，当前最多 16 项。高级选项包括完整生成 URL、自定义鉴权头名称、最大输出 token、模型上下文上限、输出长度参数和检查报告的 JSON 模式。完整生成 URL 填写后优先于根地址；普通文字回答始终不强制 JSON。

有效上下文限制为模型上限与回答总预算的较小值，包含输出预留。连接测试只验证选择的文本或结构化能力，不代表图片、文件、工具或完整回答质量已经验证。仅支持 Chat Completions；Responses、Messages、Gemini 等协议仍待实现。

“停用此模型当前的密钥关联”使新任务不再使用该密钥。为保持已接受任务可执行，旧密钥版本会继续保存在私有凭据存储中；本版没有凭据历史删除界面。更新 API Key 会创建新引用，不覆盖旧任务使用的凭据。

## 保存位置和优先级

界面从现有 `models/roles` 读取初始配置；保存的文字配置覆盖后续文字任务的对应设置。不会改写 `.env` 或 `config.yaml`，不通过修改进程环境变量切换模型或账户。网页保存后，使用同一私有目录的 `answer` 命令和 `doctor` 也能读取配置。

配置位于 `private_dir/configuration/llm.json`；未配置 private_dir 时为 `runs/current/private/configuration/llm.json`。其中只包含模型、参数、角色和凭据引用，不含密钥值。API Key 在单独的 `credentials.json` 中保存：Windows 使用当前用户 DPAPI 加密，复制到其他用户或系统后需重新输入；其他系统使用权限为 0600 的本地文件。该私有目录不进入 Git 和发布包。

公共接口只返回密钥是否已配置，不返回密钥值；页面保存后清空密码框，不将密钥写到 localStorage。测试错误不直接回显上游错误体，任务快照和诊断只保留凭据引用。配置修改接口检查本地 Host 和同源 Origin；本项目仍按本地单用户服务运行。

## 接口与实现

| 方法与路径 | 用途 |
|---|---|
| GET `/api/v2/llm-settings` | 配置 revision、模型和角色、密钥配置状态 |
| PUT `/api/v2/llm-settings` | 保存配置与可选新密钥，携带 expected_revision；版本冲突为 409 |
| POST `/api/v2/llm-settings/test` | 使用 model_id、draft 与 text／structured scope 测试草稿；不持久化密钥或配置 |

这些是当前文字配置界面的接口，不等同于文档 01 中未来的 ProviderConnection／ModelBinding 控制面。测试最多同时执行一个，每项最多两次调用、30 秒总预算；测试成功不自动切换或保存模型。

代码位置为 `llm_settings.py`、`text_api.py`、`web/llm-settings.js`，调用层通过独立凭据解析器读取私有引用或原环境变量。`TextJobManager` 在同一把锁内接受配置快照与更新默认设置，防止提交任务时混用新旧参数。

验证覆盖保存在 `tests/test_llm_settings.py`：保存后立即生成、重启读取、空密钥保留、密钥版本、明确停用、版本冲突、两类草稿测试、错误脱敏、引用边界、跨来源拒绝和环境密钥状态。浏览器操作验证使用隔离目录与受控提供商，不替换实际用户配置，也不调用真实供应商。

2026年10月29日复测与分离增补：当前 0.2.0 已与 legacy_mvp 历史项目完全分开，根目录只提供文字 API 和 serve／answer／doctor；历史原接口、Docker 和动画命令仅在归档项目可用。当前证据以[真实测试报告](../testresult/测试报告.md)和[代码审查](../testresult/代码审查.md)为准。
