# 开发计划

更新：2026-11-13。固定 pipeline、类型化个性化和记忆状态机已开始替换旧实现；本文区分本轮代码落地与尚待真实验收的能力。目标依据为[固定教学流水线架构](../design/00-固定教学流水线架构.md)。

## 本轮已实现

| 工作 | 实际行为 |
|---|---|
| 固定请求解释 | 用户当前要求一次产生 RequestIntent 与带原句的 MemoryProposal；校验后保存，后台不再调用模型提取 |
| 当前有效偏好 | 受理时冻结候选；本轮排除后按当前、主题、课程、全局、产品默认编译；读和学独立 |
| 结构化教学产物 | SourceBundle、AnswerDocument、VerifiedAnswer；正文 Markdown、单元和依赖同源，场景只取相关单元闭包 |
| 记忆状态与证据 | 规范字段值、独立会话支持、默认确认、纠正、过期、忘记、恢复、来源撤回、事务回执 |
| 独立记忆提交 | 数学、TTS或渲染失败不取消合法候选；受理序号和显式决定围栏防止迟到覆盖；提交重试不重新调用模型 |
| 可信视觉参数 | 语义颜色映射、标准/大字号、标准/低动画强度进入真实渲染与检查；新增有限多项式和离散点等类型化图形 |
| 请求与恢复 | 最终模型请求统一预算/追踪；修复保留候选；pending解释提交可恢复，场景复用绑定能力与视觉参数 |
| 迁移与管理 | 旧自由记忆导出隔离并停止旧队列；迁移须取得独占租约；Markdown仅查看导出，UI使用受控取值 |

当前结构与代码入口见[代码架构](代码架构与迁移.md)，实际记忆管理见[用户记忆](用户记忆与个性化.md)，视觉支持范围见[动画实现](动画实现与本地运行.md)。这些变化允许内部重写，没有引入通用工具规划器、会话树或摘要 agent。

本轮本地验证为554项Python回归、98项前端测试和7项单独运行的原生渲染测试通过，安装包隔离检查通过；证据边界见[实现验收报告](../../testresult/fixed-pipeline-20261113/报告.md)。

## 仍需完成

1. 对固定模型版本开展请求解释语义验收：同义、反义、引用人物、本次例外、跨日要求与课程范围；程序字段校验不能代替语义正确性。
2. 对结构化正文和视频开展真实数学与音画验收，检查必要推理、图形含义、旁白、颜色角色和跨场景一致性。确定性测试及原生渲染不等于真实模型生成质量通过。
3. 扩展受影响阶段的恢复与增量重算。现已有记忆提交恢复和视频场景续跑，尚未提供任意阶段自动恢复或完整依赖缓存系统。
4. 按产品需要补齐课程/主题选择界面、显式恢复与来源撤回的管理体验；底层范围和撤回接口已实现，当前任务页面默认全局范围。
5. 在实际旧库样本上演练导出隔离与重新确认规范值，明确需要用户处理的数据，不用新层级伪装旧证据。

真实运行需保存首次成功/失败、修复输入、用量与环境，不能只保留成功样例。当前没有重新启动付费模型评测，也没有恢复已停止的学生模拟。

## 历史证据边界

大一数学分析模拟按用户要求在第13轮结束后停止，第14–20轮未执行。主轨迹是1轮完整成片、9轮仅正文、3轮正文被阻断；自然晋升与配色遵循未整体通过。原报告及独立固定原句、清退和场景控制实验保留在[历史模拟报告](../../testresult/memory-visual-20261111/报告.md)与[记忆验证](../../testresult/memory-visual-20261111/记忆验证.md)。

这次重写改变了配色执行和偏好归并位置，但不能据此将旧失败改记成功。旧[结构清理报告](../../testresult/cleanup-20261111/报告.md)和[后台沉淀验收](../../testresult/memory-consolidation-20261106/报告.md)只说明当时实现。

## 生产验收

目标成片仍为120–360秒、1280×720、30fps。视频阶段P95不超过8分钟、整体不超过10分钟仍待测量；固定请求解释增加前台调用，旧预算数据不可直接沿用。口径见[生产验收](../design/动画时长与生产验收.md)。

支持范围内至少10题×3次真实运行，报告首次文字/视频合格率、人工严重问题、阅读时间、TTS发音、P95、超时与partial、所有显式重试成本。正确拒绝不支持内容不能计为视频成功。最终仍需完整人工看片，自动检查和关键帧只能覆盖部分问题。

## 产品边界

- 用户当前明确要求优先于历史默认，但不降低数学正确性、来源及发布标准。
- 一次任务冻结配置、记忆和参数，后台更新只影响后续受理任务。
- 文字发布而视频失败可交付partial；请求配音时，TTS失败不能改交静音并声称完整成功。
- 不执行模型生成的任意Python；不支持的硬要求明确报告。
- 不由学习内容、阅读记忆或媒体成功推断掌握度。生成器改进进入离线回归，不写学生记忆或自动修改系统提示词。
- 删除有效偏好影响未来任务；彻底擦除历史Answer、视频及快照是独立操作。

通用对话内核、动态工具发现、向量检索、LLM总摘要、掌握度跟踪和连续课程不作为本轮前置。研究与投稿仍需独立方法对照；模拟学生不能解释为真人学习收益，见[研究方案](../research/个性化记忆与投稿研究方案.md)。
