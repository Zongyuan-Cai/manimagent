## 真实渲染验证

已构建包含 Manim 0.20.1、LaTeX、Noto CJK 字体、FFmpeg 和 ffprobe 的 Linux 渲染镜像。基础镜像通过摘要固定，生成代码在禁网、非 root、限制资源的独立容器中执行。

CLI smoke 实际渲染并合成了一个手写向量投影场景，验证结果为：

| 项目 | 结果 |
|---|---|
| 视频尺寸 | 1280×720 |
| 帧率 | 30 fps |
| 编码与像素格式 | H.264、yuv420p |
| 时长 | 5 秒 |
| 中文与公式 | 中文标题与 MathTex 正常，已查看抽帧 |
| 合成与解码 | 成功合成并完成解码检查 |

真实渲染集成测试进一步使用受控模型响应，实际运行预览渲染、四帧抽取、正式渲染、产物登记与合成。该测试验证组件联通，不验证真实模型的规划或 VLM 判断质量。

## 双输出改造待验证

以下为后续验证任务，尚无通过结论：

- 仅重试动画不增加回答调用；并发重试、答案修订和旧视频的版本绑定正确。
