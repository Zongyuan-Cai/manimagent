# MVP 验证记录

验证日期：2026年10月17日

本记录对应第一阶段 0.1.0 MVP。已完成纯文本入口、模型适配、规划、生成与修订、隔离渲染、视觉检查流程、任务队列、CLI 和本地网页的代码实现。

## 自动化验证

启用真实 Docker 测试的完整测试集通过 84 项。常规运行中，83 项无需模型或 Docker 的测试通过，1 项真实渲染测试按环境变量选择执行。Ruff 检查和格式检查通过，JavaScript 语法检查通过。

测试覆盖纯文本边界、未知字段与非法 Unicode、规划引用、跨平台名称冲突、检查评分与覆盖规则、服务响应校验、一次重试、总时间与调用预算、累计修订预算、正式检查失败、部分场景失败、API 状态与视频范围请求、队列容量、任务恢复和产物路径限制。

模型请求通过 MockTransport 检查请求结构、图像 data URL、用量统计和服务异常。流程测试使用仅位于 tests 目录的受控模型与渲染响应；生产代码没有模拟成功模式或默认通过的视觉检查。

## 真实渲染验证

已构建包含 Manim 0.20.1、LaTeX、Noto CJK 字体、FFmpeg 和 ffprobe 的 Linux 渲染镜像。基础镜像通过摘要固定，生成代码在禁网、非 root、限制资源的独立容器中执行。

CLI smoke 实际渲染并合成了一个手写向量投影场景，验证结果为：

| 项目 | 结果 |
|---|---|
| 视频尺寸 | 1280×720 |
| 帧率 | 30 fps |
| 编码与像素格式 | H.264、yuv420p |
| 时长 | 5 秒 |
| 中文与公式 | 中文标题与 MathTex 正常，已查看抽帧 |
| 合成与解码 | 成功合成并完成解码检查 |

真实渲染集成测试进一步使用受控模型响应，实际运行预览渲染、四帧抽取、正式渲染、产物登记与合成。该测试验证组件联通，不验证真实模型的规划或 VLM 判断质量。

## 网页与打包

本地网页已启动并检查纯文本控件、示例填入、字符计数、未配置服务时的提示。API 测试验证状态查询、下载与视频 Range 请求，页面静态资源可正常返回。

已构建 sdist 与 wheel，并核对 wheel 包含容器驱动、HTML、CSS 和 JavaScript，不包含运行数据或 .env。GitHub Actions 配置运行基础检查、无需 Docker 的测试和打包；远端执行结果以对应 workflow 为准。

## 尚未验证的范围

按当前安排，真实文本与视觉模型的服务、模型名和密钥稍后配置。因此尚未进行真实 API 端到端生成实测，未报告真实模型的生成成功率、VLM 判断准确率或调用成本。

手写渲染样例和受控模型集成测试不能代替这一实测。配置完成后，使用[固定输入样例](mvp/输入与验收样例.md)开展基线运行并人工检查完整视频，再更新本记录。
